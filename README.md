## Assignment Features

- Layered hero decoration using CSS position and z-index.
- Three rounded profile card styles: light, dark, and accent.
- Sticky navigation bar.
- Fixed floating back-to-top button.
- Scrollable notes panel using overflow: auto.
- Responsive horizontal tile strip.
- Annotated CSS box-model illustration.
- Content, padding, border, and margin demonstration.
- Responsive desktop, tablet, and mobile layouts.
- Global box-sizing: border-box.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Resize the browser to test the responsive design.

No build tools or external libraries are required.
